# React

A comprehensive collection of React learning materials, course exercises, notes, and hands-on implementations covering React fundamentals, state management, data fetching, and rendering strategies.


## Topics Covered

- **React Fundamentals:** Components, component lifecycle, and core React concepts.
- **Code Splitting & Lazy Loading:** Improving application loading by splitting bundles and loading components on demand.
- **Server-Side Rendering (SSR):** React SSR implementation using Node.js and Webpack, with separate client and server configurations.
- **React Query:** Queries, fetching data by ID, query types, custom hooks, Axios interceptors, mutations, and optimistic updates.
- **Redux:** State management using Redux.
- **Learning Resources:** Course exercises, tutorials, implementation examples, and personal notes from multiple React learning resources.


## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/naba93980/react.git
   cd react
   ```

2. Navigate to any individual project directory.

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the project using the script defined in its `package.json`, typically:

   ```bash
   npm start
   ```

   Refer to the individual project's `package.json` for its available scripts and setup requirements.


## Repository Structure

- `React_concepts/` — Code splitting, lazy loading, and SSR implementations.
- `React-Query/` — Multiple React Query demos exploring data fetching and mutations.
- `React-redux/` — Redux implementation and examples.

## Purpose

A hands-on learning repository documenting React concepts through practical implementations, experiments, and notes.
